## 示例正常 CW 的关键时刻

初始偏差 +18°，偏航速度参数 18°/min，示例机舱速度 0.3°/s，停止方式 1。

| 时间 | 执行情况 |
| --- | --- |
| 0.0 s | 上电检查请求物理停止，启动 22 s 停止脉冲 |
| 30.1 s | 接受逻辑 CW 启动；T=60 s，H=30 s；液压阀打开 |
| 32.1 s | 电磁制动器开闸命令 ON |
| 33.1 s | CW 电机输出 ON，机舱开始运动 |
| 60.1 s | 逻辑 H 到期，开始监督对准条件 |
| 90.1 s | 逻辑 T 到期，进入延长阶段 |
| 90.3 s | 1 s 风向均值严格进入 +1° 内，逻辑停止并请求物理停止 |
| 90.4 s | 跟踪程序检测到逻辑下降沿，启动 5 s 抑制 |
| 91.3 s | 1 s 停止延时完成，电机 OFF |
| 92.3 s | 合闸延时完成，电磁制动器开闸命令 OFF |
| 95.4 s | 5 s 逻辑抑制完成 |
| 112.3 s | 22 s 物理停止脉冲完成 |
| 121.4 s | 电机关闭后的重启 TON 完成 |

因此逻辑停止后，机舱还随电机运行 1 秒、转动 0.3°。
这段运动已计入偏差积分和动作成本。

## 八类轨迹的物理停止

各场景均在示例时间 33.1 s 启动电机。

| 场景 | 电机 OFF | 条件 |
| --- | --- | --- |
| `normal_cw` / `normal_ccw` | 91.3 s | 固定 1 s 停止延时 |
| `wind_time_stop` | 101.3 s | 示例 8 m/s 对应 11 s 延时 |
| `pressure_stop` | 94.5 s | 示例压力反馈严格超过目标 |
| `pressure_timeout` | 105.3 s | 15 s 安全超时 |
| `wind_loss` / `electrical_open` / `mode_exit` | 46.0 s | 45 s 触发停机条件后完成 1 s 延时 |

`runs/plc_yaw/verified_replay/`，这些大体积生成文件不进 Git。
